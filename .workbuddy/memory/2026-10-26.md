## DDD 事件驱动 Demo（/Users/donglee/IdeaProjects/demo）

在原有 Spring Boot 4.1.2 + Java 21 空工程上，生成了一套可运行的 DDD 事件驱动示例（订单上下文）。

### 分层与关键类
- `shared/domain`：`DomainEvent`、`AggregateRoot`（登记/拉取事件）、`DomainEventPublisher`（端口）、`DomainException`
- `shared/infrastructure`：`SpringDomainEventPublisher`（写 EventStore + Spring 多播）、`DomainEventStore`（审计/回放）、`outbox`（OutboxEvent/OutboxStore/OutboxRelay/DomainEventOutboxHandler）、`idempotency/ProcessedEventRegistry`
- `order/domain`：`Order` 聚合（place/confirm/pay/cancel，状态机 + 不变量）、`OrderId`/`OrderItem`/`Money` 值对象、4 个领域事件、`OrderRepository` 端口
- `order/application`：`OrderApplicationService`（保存后发事件）、`PlaceOrderCommand`、CQRS 查询侧 `OrderView`/`OrderViewStore`/`OrderQueryService`
- `order/infrastructure`：内存仓储、读模型投影 `OrderProjectionHandler`（含 `rebuild()` 全量重放）、通知监听器
- `order/interfaces/rest`：`OrderController`（含 `/events`）、`GlobalExceptionHandler`（ProblemDetail）
- 独立上下文：`inventory`（订阅 Created/Cancelled，预占/释放库存）、`loyalty`（订阅 Paid，带 eventId 幂等，10 元 1 分）
- `admin/DiagnosticsController`：/api/diagnostics/{events,outbox,stats,outbox/flush,projections/rebuild}

### 验证结果
- `./mvnw test`：7 个测试全部通过（DemoApplicationTests + OrderFlowIntegrationTest 6 个用例）
- 实机启动后 curl 走通：下单 CREATED→confirm→pay PAID，事件 3 条、库存 100→98、积分 +79、Outbox 定时投递到 topic=order-events（key=orderId）、重建读模型重放 5 条事件
- 异常映射验证：重复支付已取消订单 400、不存在订单 404、空商品行 400

### 环境注意
- 本机无 `mvn`，用 `./mvnw`；离线模式（-o）会因插件依赖缺失失败，需联网。
- 沙箱注入 `SERVER__PORT` 环境变量会覆盖 `server.port`，本地验证时用 `-Dspring-boot.run.arguments=--server.port=18080` 显式指定端口。
- curl 访问本机需加 `--noproxy '*'`（沙箱有 HTTP_PROXY）。

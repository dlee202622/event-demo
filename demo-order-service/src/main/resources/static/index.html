微服务事件驱动 Demo — Order / Inventory / Loyalty
架构：三个独立服务通过 RabbitMQ Topic Exchange 通信。
Order(9001) 发布订单事件 → Exchange 广播 → Inventory(9002) 预占库存 / Loyalty(9003) 累计积分
Inventory 预占失败 → 发布补偿事件 → Order 自动取消订单
